# Importancia del repositorio
Un repositorio en GitHub es el núcleo de almacenamiento y gestión de un proyecto; funciona como una carpeta digital en la nube que guarda el código principal, los archivos y todo el historial completo de versiones de lo que se ha modificado(el código en si).
